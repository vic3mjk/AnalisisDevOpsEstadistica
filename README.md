- R >= 4.2
- RStudio
- tidyverse
- moments

- knitr

## Ejecución

1. Clonar el repositorio.
2. Abrir `bitacora_devops.Rmd` en RStudio.
3. Instalar las dependencias.
4. Ejecutar/Knit el archivo.
5. Se generará el reporte HTML.
