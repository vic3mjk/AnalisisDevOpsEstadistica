# Análisis de Métricas de Software y DevOps
Proyecto Integrador · Probabilidad y Estadística Computacional  
**Autor:** Vicente Alonso Sepúlveda Montoya  

## Descripción del Proyecto
Repositorio que contiene el desarrollo del laboratorio de análisis estadístico sobre métricas de DevOps (~5,000 registros simulados) usando R[cite: 1, 11].

## Estructura
- `devops_metrics.csv`: Dataset simulado[cite: 1].
- `bitacora_devops.Rmd`: Código fuente en R Markdown[cite: 3].
- `bitacora_devops.html`: Reporte reproducible[cite: 3, 11].
